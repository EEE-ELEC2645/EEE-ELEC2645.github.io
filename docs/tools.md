# Tools

Every engineer needs good tools. Ours mostly need Wi-Fi.

These pages cover the tools you use alongside the C, from the first week: the Codespace you write and run your code in, Git and GitHub for keeping and sharing your work, Markdown for your READMEs, and the code style used throughout the module. They matter even more in the Unit 4 group project, where your whole group works on one repository.
