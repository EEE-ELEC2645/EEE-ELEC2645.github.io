# Console libraries

Someone else already fought the SPI timing diagrams, so you do not have to.

The games console hardware comes with libraries that do the low-level work for you: the LCD driver draws text, shapes and sprites on the screen, and the joystick library turns raw ADC readings into positions and directions for your game. These pages explain how each library works and list its functions. The microcontroller features underneath them, such as SPI, ADC and timers, are in the [STM32]({% link docs/stm32/STM32.md %}) section.
